Privacy Policy

Reels Everyday Shorts Uploader - last updated 6 November 2026

What it does

This is a personal tool used only by the owner of the Reels Everyday YouTube channel. It signs in with the owner's own Google account and uses the YouTube Data API to upload videos to that channel.

Data it accesses

It requests permission only to upload videos to the owner's own YouTube channel. The sign-in token is stored only on the owner's own computer.

Data it does not collect

It collects no personal data from anyone. It does not read other users' data, use cookies or analytics, or sell or share any information with third parties.

Google API Services

Use of information received from Google APIs follows the Google API Services User Data Policy, including its Limited Use requirements. The tool also uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.

Contact

Questions can be sent through the Reels Everyday YouTube channel.
